# Reading the AFCON dashboard

[Project overview](../README.md) · [Metric definitions](metric-definitions.md)

This guide documents the structure of the author's existing `AFCON REPORT (1).pdf`, a five-page dashboard export. It is not a replacement for that report, a newly calculated results table or evidence that the underlying data has been revalidated.

## 1. Tournament history

Start with the era and region selections. The page brings together hosting patterns, champions and regional title distribution. Its hosting timeline extends beyond the modern results window, so count completed editions separately from scheduled hosts.

For co-hosted tournaments, distinguish the number of editions from the number of host-country assignments. One edition with multiple hosts must not become several editions in a tournament-total KPI.

## 2. All-time team analysis

The page compares participation and performance, match records and points, alongside scorer comparisons. Read exposure and output together: more appearances provide more opportunities to accumulate results.

Scatter-plot reference lines define a comparison framework. Their selected sample and filter behaviour should be stated before interpreting labels such as high impact or underperformance.

## 3. Modern-era team consistency

This section looks at podium finishes and progress into later stages. Confirm the period and eligible teams before comparing its totals with the all-time page.

A team can appear in more than one nested stage count within the same edition. Do not add quarter-final, semi-final and final appearances and describe the sum as unique tournaments. A consistency score needs its formula and weights published before readers can reproduce it.

## 4. Player achievement

Read scorer totals, goalkeeper recognition, best-player awards and repeated title-winning participation as different measures. Award eligibility and historical availability may vary. Distinguish a team's titles from the titles won by a specific player.

## 5. Attendance and stadium efficiency

Read attendance totals, attendance per match and capacity utilisation separately. The denominator and sample coverage determine the meaning of each measure.

Compare editions using the same set of known-attendance matches where possible. Missing attendance is not zero attendance. A ratio stored as 0.951 and formatted as a percentage is 95.1%; multiplying again would misstate the result.

## Publication checks

Before using a screenshot as a headline finding, verify its filter state, period, table coverage and source. Reconcile repeated KPI definitions, review percentage scaling and replace any unavailable or licence-blocked visual with an exportable alternative.

The PDF and Power BI model are not bundled in this repository yet. This guide records what the existing export contains without manufacturing screenshots or claiming access to the model's measures.
